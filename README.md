# 厦门大学马来西亚分校算法竞赛（程序设计竞赛）兴趣小组

## 小组简介

这是一个由厦门大学马来西亚分校学生自发组织的兴趣小组，致力于为我校学生在 [ICPC](https://icpc.global) / [CCPC](https://ccpc.io) / [GPLT 团体程序设计天梯赛](https://gplt.pintia.cn)的报名、注册队伍和训练等事务上提供力所能及的帮助。

代码与知识库：

- [XMUM XCPC Wiki](https://xiamen-university-malaysia.github.io/xcpc-wiki)
- [Xiamen-University-Malaysia/xcpc-wiki](https://github.com/Xiamen-University-Malaysia/xcpc-wiki)

## 小组招新

如果你非常热爱算法竞赛且有一定基础、有参赛意愿（因为要[自费参赛](https://research.xmu.edu.my/guidelines-innovation)），欢迎加入我们！

联系方式：

- 执行组长微信：zeyu10007
- 小组主要邮箱：[xmumcpc2025@outlook.com](mailto:xmumcpc2025@outlook.com)

备注：

- 请附曾获奖项，优先考虑 NOIP 省二 / CSP-S 省二 / CSP-J 省一 / 蓝桥杯省一 / 百度之星省铜及以上的参赛选手。
- 学校[竞赛库](https://research.xmu.edu.my/resources)收录了 ICPC World Finals / ICPC Regional 以及 GPLT 天梯赛，暂未收录 CCPC 系列比赛，如有想通过竞赛保研加分的同学请谨慎考虑。
